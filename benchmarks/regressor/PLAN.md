# c2 regressor — GPU phase (revised)

Goal-orientated plan for a regressor accurate enough to **classifier-guide SDXL toward
a target c2**. This is the corrected version of the original `PLAN.md`; the
"What changed and why" box below lists every deviation and the evidence for it.

---

## What changed from the first draft (and why)

| # | Original plan | Problem found | Fix in this plan |
|--:|---------------|---------------|------------------|
| 1 | Crop→resize augmentation as "8× data", labels measured at 512 | Crops/resizes change the multi-scale content, so the true c2 ≠ the stored label. `check_c2_invariance.py` measures `mean|Δc2|` ≈ **6–8** for crop/downscale. | **Geometric-only augmentation** (H/V flip + 90° rot = 8×, `mean|Δc2|`≈0.01). Brightness/contrast also dropped — their [0,1] clip shifts c2 by **>2.0** on heavy-tailed fields. |
| 2 | Reuse `build_dataset` PNGs | `build_dataset` measures c2 on the *raw* field but saves the *punch*-stretched image; punch is a nonlinearity that flattens c2 (−1.0 → −0.43). | Corpus measures c2 on the **exact array it stores** (`build_corpus.py`). |
| 3 | Store everything as 8-bit PNG | 8-bit quantization of heavy-tailed cascade fields collapses the near-zero mass → sparse-field artifact, c2 −1.0 → **−50**. | Generated fields stored as **float `.npy`** + labelled on the faithful field; only true photos use 8-bit. |
| 4 | 80/10/10 split "by source" | Splitting by image leaks: the same SDXL prompt's seeds land in both train and test → inflated RMSE. | **Group-aware split**: diffusion grouped by prompt, generated by family / c2-band; assertion enforces no group straddles splits. |
| 5 | Stage 2 budget "4–6 h" for 3–5k images | Measured throughput is **9.9 s/img** (52.9 min / 320 @ 28 steps). 3–5k @ 30–50 steps is **~12–20 h**. | Corrected budget below + **c2-balanced rejection sampling** instead of blind 5k. |
| 6 | `features.npz` cache *and* per-epoch augmentation | Mutually exclusive — you can't cache features and augment through the backbone. | `--cache-features` is an explicit *no-aug* fast path; default augments live. |
| 7 | "Current state … this commit" with r=0.88 | The CPU MVP / those metrics are **not committed** to the repo. | Stage 0 is a deliverable here; the v2 metrics are the first reproducible baseline. |

## Current state (honest)

- No regressor is committed yet. The r=0.88 / diffusion-RMSE-0.22 numbers from the
  draft came from an uncommitted workspace and are **not reproducible from this repo**.
- What *is* in the repo and reusable: `mfractal.wavelet_leaders_2d` (the c2 estimator),
  `mfractal.generate` / `mfractal.prescribed_cascade` (free CPU image sources), the
  pareidolia set (106 labelled PNGs), and the diffusion **labels** (`analysis.csv`, 320
  rows). The 320 diffusion **PNGs are gitignored** (`benchmarks/diffusion/out/*/`) — they
  must be present locally (from the original run) or regenerated with `generate.py`.

## Goal

Regressor good enough to drive classifier-guidance in SDXL for target c2 ∈ [−0.5, −0.02].
**Acceptance:** diffusion-domain test RMSE < 0.10; latent variant within 0.02 RMSE of
pixel variant; end-to-end (prompt × seed × c2_target) grid where measured c2 of the SDXL
output tracks c2_target at slope ≈ 0.8, r > 0.85.

## Stage 0 — assemble the labelled corpus (CPU, ~30–60 min, no GPU)

`build_corpus.py` builds one manifest with a single consistent labelling convention.

```bash
# free layers + on-disk photos (run on the GPU box where the diffusion PNGs live):
python build_corpus.py --all
# add your real macro-texture photos (you are providing these):
python build_corpus.py --macro /path/to/macro_textures --append
# scale the free c2-coverage layer up (CPU, basically free):
python build_corpus.py --prescribed --prescribed-grid 60 --prescribed-seeds 16 --append
python check_c2_invariance.py      # sanity: confirms the augmentation set on YOUR data
```

Sources (the hybrid you chose): **procedural** + **prescribed_cascade** (free CPU, the
latter gives clean uniform c2 coverage across [−1.45, −0.02]) + **diffusion** (exact
deployment domain) + **pareidolia** + **macro photos** (real photographic statistics,
supplied by you). Output: `corpus/manifest.csv` (path, c1, c2, source, group) +
`corpus/images/*.npy`.

## Stage 1 — DINOv2 backbone + head (1–2 h GPU)

`train_stage1.py`. Frozen `facebook/dinov2-small` (CLS, 384-d) + MLP head 128→64→1,
dropout 0.3, weight_decay 1e-3, cosine LR 1e-3→1e-5, early stop on val MSE, geometric
augmentation only, group-aware split, robust per-image input normalization.

```bash
python train_stage1.py --epochs 300            # frozen + live augmentation
python train_stage1.py --finetune --lr-backbone 1e-5   # unfreeze (decision point)
```

**Pass:** diffusion-domain RMSE < **0.15** → backbone is doing real work, proceed.
Else jump to Stage 2 (data, not architecture, is the limiter).

## Stage 2 — c2-balanced diffusion data (≈12–20 h GPU, checkpointable)

**Not** blind 5k. Generate → measure c2 → keep into under-filled c2 bins until each bin
across [−1.0, −0.02] has N (rejection sampling). Reuse `benchmarks/diffusion/generate.py`;
vary CFG (5,7,9) and steps (30,50) to broaden the natural c2 spread. Label with
`build_corpus.py --diffusion` (re-measures at 512). Realistic cost at the **measured 9.9
s/img**: ~1.5–3k *targeted* images ≈ 6–12 h beats 5k blind ≈ 14–20 h for better coverage.

**Pass:** diffusion-domain RMSE < **0.10** → regressor is production-ready.

## Stage 3 — latent-space regressor (2–3 h GPU)

Encode Stage-2 images through SDXL VAE → 4×128×128 latents (cache `.npz`). Small CNN
(3–4 stride-2 conv blocks + GAP + MLP, ~2M params) trained on the **same c2 labels** so
it's directly comparable. **Risk (already anticipated):** c2 lives in the finest octaves
the 8× VAE blurs; if the latent gap > 0.05, fall back to pixel-space + VAE decode in the
loop.

**Pass:** latent RMSE within **0.02** of pixel RMSE.

## Stage 4 — classifier-guidance integration (3–4 h GPU)

Guide on the **x0-prediction** (DPS/FreeDoM-style — the right call, already in the draft):

```python
with torch.enable_grad():
    latent.requires_grad_(True)
    eps = unet(latent, t, prompt_embeds)
    x0_pred = (latent - sigma_t * eps) / alpha_t
    loss = ((regressor(x0_pred) - c2_target) ** 2).mean()
    grad = torch.autograd.grad(loss, latent)[0]
eps_guided = eps + guidance_scale * sigma_t * grad
```

**Note added:** the regressor is trained on clean images, but early-step `x0_pred` is
blurry → unreliable gradients. Gate guidance to start after ~step 10, or anneal
`guidance_scale`. Tunables: c2_target ∈ [−0.5, −0.02], guidance_scale ∈ [50, 500],
deterministic sampler (DDIM/Euler). Validate on 4 prompts × 3 seeds × 5 c2_targets = 60
images; plot measured vs target c2 (target slope > 0.7, r > 0.85).

**Failure modes:** too weak → no shift (raise scale); too strong → oversharpened/distorted
(lower scale); infeasible (prompt, c2) combos — stay inside the trained c2 range.

## Decision points

- **After Stage 1:** diffusion RMSE ≥ 0.18 with DINOv2 → architecture isn't the limiter;
  go to Stage 2. Also try `--finetune` before concluding.
- **After Stage 2:** diffusion RMSE ≥ 0.12 with balanced data → consider an SDXL-VAE-tuned
  encoder or a from-scratch 512² CNN. Reconvene before more compute.
- **After Stage 3:** latent gap > 0.05 → pixel-space + VAE decode (3× slower, works);
  < 0.02 → latent is the deployment path.
