# Fractal Visuals

This repository contains tools and notebooks for generating and analyzing fractal-based visual stimuli.  

---

## Features

- **Cloud-like image generation**  
  Create images with varying **fractal dimensions (FD)** using noise-based algorithms.  

- **Fractal dimension computation**  
  Compute the FD of generated images for quantitative analysis.  

- **Exploration of multifractality**  
  Early experiments and notebooks exploring multifractal properties in visual patterns.  

---

## Contents

- Python scripts for generating fractal images and calculating FD.  
- Jupyter notebooks for experiments and visualization.  
- Exploratory code on **multifractality** and alternative fractal generation techniques.  

---

## Use case

These tools were originally developed for research on **pareidolia and creativity**, where participants viewed cloud-like fractal images of varying complexity.
